# Concord

Downloads oficiais do Concord para Windows. Este repositório distribui os instaladores; o código-fonte é mantido separadamente.

## Baixar

**[Baixar Concord para Windows (64 bits)](https://github.com/multiheros/concord-downloads/releases/latest/download/Concord-Setup.exe)**

[Ver versões e novidades](https://github.com/multiheros/concord-downloads/releases/latest) · [Checksum SHA-256](https://github.com/multiheros/concord-downloads/releases/latest/download/SHA256SUMS.txt)

## Instalar e usar

1. Feche o Concord caso ele esteja aberto.
2. Baixe e execute **Concord-Setup.exe**.
3. Abra o app e entre com sua conta. Em uma sala de voz, escolha compartilhar uma janela ou tela e confirme em **Compartilhar**.

Para jogos, selecione a janela do jogo e o perfil **Jogos — até 1440p, 60 fps**. Prefira executar o jogo em janela sem bordas.

## Requisitos e disponibilidade

- Windows de 64 bits. A captura nativa de janela requer Windows 10 1903 ou posterior e GPU NVIDIA com NVENC/driver compatível.
- O áudio do sistema ainda não está disponível no compartilhamento nativo desta versão.
- Captura de monitor e o modo alternativo de captura precisam do `ffmpeg.exe` instalado no PATH ou ao lado do executável. O instalador não inclui FFmpeg; a captura de janela WGC/NVENC não precisa dele.

O Concord está em fase de piloto. As notas de cada versão informam as novidades e limitações conhecidas.
